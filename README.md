# Simple Interest Calculator

A simple Bash-based calculator that computes simple interest based on user input.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

The calculator asks the user to enter:

- Principal amount
- Rate of interest
- Time period

## Usage

Run the script using:

```bash
bash simple-interest.sh
```

The calculator asks for the principal amount, rate of interest, and time period and displays the calculated simple interest.
